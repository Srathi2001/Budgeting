Form fields: text and amount inputs, select, read-only and error states, with an uppercase label.

**Consumer provides:** label, value, error message when invalid, and `readonly` / `aria-invalid`.

- Amount inputs right-align with `.anh-num`.
- Read-only fields use a dashed border and `cell-locked` fill — the same language as locked table cells.
- Errors: 2px ink border with hatch, and a short bold message. No helper text otherwise.
